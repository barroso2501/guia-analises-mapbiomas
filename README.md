# Guia das análises temporais do MapBiomas

Guia em português, para colegas da TNC Brasil que estão começando no Meu MapBiomas: o que cada uma das 16 análises da plataforma responde e como interpretar os resultados.

**Leia o guia em:** `https://<seu-usuario>.github.io/guia-analises-mapbiomas/` (troque `<seu-usuario>` depois de publicar)

## Arquivos

| Arquivo | O que é |
|---|---|
| `index.md` | O texto do guia. É o único arquivo a editar no dia a dia |
| `_config.yml` | Título, idioma e tema do site |
| `img/` | Figuras dos quatro pixels de exemplo, uma por análise |

## Como editar

1. No GitHub, abra `index.md` e clique no lápis (*Edit this file*).
2. Altere o texto. Títulos começam com `#`, negrito fica entre `**`, e imagens são `![descrição](img/arquivo.png)`.
3. Clique em *Commit changes*. O site se atualiza sozinho em 1 a 2 minutos.
