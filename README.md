# Meu MapBiomas: tutorial e guia das análises

Material em português para colegas da TNC Brasil que estão começando no Meu MapBiomas:

- **Primeiros passos** (`tutorial.md`): como criar um projeto e a lógica de cada passo, com o Parque Nacional da Serra da Capivara como exemplo.
- **Guia das análises temporais** (`index.md`): o que cada uma das 16 análises da plataforma responde e como interpretar os resultados.

**Leia em:** `https://<seu-usuario>.github.io/guia-analises-mapbiomas/` (troque `<seu-usuario>` depois de publicar)

## Arquivos

| Arquivo | O que é |
|---|---|
| `index.md` | Guia das análises (página inicial do site) |
| `tutorial.md` | Tutorial de primeiros passos |
| `_config.yml` | Título, idioma e tema do site |
| `img/` | Figuras do guia (quatro pixels de exemplo, uma por análise) |
| `img/tutorial/` | Diagrama e capturas do tutorial |

## Como editar

1. No GitHub, abra o arquivo `.md` e clique no lápis (*Edit this file*).
2. Altere o texto. Títulos começam com `#`, negrito fica entre `**`, e imagens são `![descrição](img/arquivo.png)`. Não apague os marcadores `{#...}` no fim dos títulos: são os destinos dos links do índice.
3. Clique em *Commit changes*. O site se atualiza sozinho em 1 a 2 minutos.

No tutorial, os trechos *[Imagem a inserir — vídeo m:ss]* indicam a imagem que falta e o minuto da gravação do treinamento de onde ela virá.
